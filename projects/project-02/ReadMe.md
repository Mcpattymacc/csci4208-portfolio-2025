## How to Demo (grader script)
1) Open the live URL above.
2) use the left and right arrow keys to move the piece left and right
3) use the up and down arrows to rotate the piece counter-clockwise and clockwise respectively
4) use the x key to "soft-drop" a piece, making it fall faster, and use the spacebar to "drop" the piece, dropping it as far as it can down
5) press z to hold a piece for later
6) fully fill a line with pieces to earn points, and try to earn as many as possible
